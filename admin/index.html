  • Giá chưa xác nhận được để “Call for pricing”.

Lưu từng mục sau khi sửa. “Xem trước” dùng bản nháp trong cùng trình duyệt. Khách truy cập bình thường vẫn đọc content.json đã triển khai. Giữ bản sao file trước khi thay thế nội dung đã xuất bản. Sau khi đưa JSON vào repository, chạy npm run build để đồng bộ HTML trước khi triển khai.
